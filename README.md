# SONORA — YouTube → Audio

Мобильный сайт для сохранения аудио из **собственных видео или материалов, на которые есть разрешение**. На телефон ничего устанавливать не требуется — Python, FFmpeg и Deno работают на сервере.

- Исходный аудиопоток без перекодирования
- MP3 320 кбит/с / 192 кбит/с
- Название, канал, обложка, длительность
- Ссылки YouTube, Shorts, youtu.be
- Ограничения: до 60 минут и 100 МБ

## Как опубликовать на Render с телефона

1. Открой https://dashboard.render.com и подключи GitHub GraperBro.
2. Нажми New → Blueprint и выбери репозиторий GraperBro/Sonora.
3. Render использует файл render.yaml и собирает Docker-образ с FFmpeg и Deno.
4. Укажи APP_PASSWORD — придумай **свой** длинный пароль и введи в Render (не записывай его в GitHub). Если при создании переменную не спросили, добавь в разделе Environment веб-сервиса.
5. После успешного развёртывания открой выданный URL. Логин: sonora. Пароль: установленный APP_PASSWORD.

GitHub Pages не запускает backend — требуется Render или другой хостинг с Docker. Облачные IP могут блокироваться YouTube; успешное скачивание на Render не гарантируется. Бесплатный Render может засыпать. 320 кбит/с не улучшает качество исходного файла. Соблюдайте права на скачивание материалов и правила YouTube.

## Локально

pip install -r requirements.txt
python app.py

Дополнительно нужны ffmpeg и deno в PATH. Локальный адрес: http://127.0.0.1:5000
